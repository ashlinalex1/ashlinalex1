## 🚀 Featured Projects

### 📝 DocuBear — Automated Code Documentation Updation
`Python` `FastAPI` `Next.js` `Agentic AI` `RAG` `FAISS` `BM25`

AI-powered documentation system that keeps repository docs continuously in sync with the codebase.
- 🔹 Hybrid RAG pipeline (FAISS + BM25) to auto-generate and update docs from code changes
- 🔹 Multi-agent architecture — code-understanding, documentation-writer, and validator agents
- 🔹 Coordinated by an orchestrator, triggered via GitHub webhooks

### 🤖 Qubit — Automated Question Paper Generation
`Python` `FastAPI` `Next.js` `Agentic AI` `RAG` `Pinecone`

Multi-agent system that generates syllabus-specific, examination-ready question papers end to end.
- 🔹 Multi-agent orchestration + RAG aligned to Bloom's Taxonomy
- 🔹 AI-driven validation with human-in-the-loop approval
- 🔹 Automatic answer-key generation and structured paper assembly

### 🚦 StreetSmart — Road Safety Compliance Monitor
`Python` `YOLOv8` `TensorFlow` `React` `Computer Vision`

Real-time computer vision system for helmet and seatbelt violation detection.
- 🔹 ~91% mAP@0.5 IoU on a custom-labelled dataset of 500+ images
- 🔹 Fine-tuned with TensorFlow-based augmentation — ~12% recall improvement over baseline
- 🔹 Deployed with a React dashboard connected via REST API for live monitoring

### 📈 Chaava — AI-Powered Stock Market Analyst
`Python` `PyTorch` `MERN Stack` `REST API` `NLP` `Flask`

Full-stack AI web app delivering real-time stock insights from live news feeds.
- 🔹 Python NLP microservice — ~50% reduction in research time
- 🔹 PyTorch-based financial sentiment classification (positive/negative/neutral) — ~78% validation accuracy
